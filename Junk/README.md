# Junk

Folder ini menyimpan dokumentasi atau catatan yang tidak lagi dipakai sebagai referensi aktif.

Isi yang saat ini diarsipkan di sini mencakup:

- dokumentasi transisi lama
- root runtime legacy yang dulu hidup langsung di `active/`
- script legacy yang tidak lagi dipakai flow aktif
- config clasp root lama yang tidak lagi dipakai deployment aktif

Aturan baca:

- jangan gunakan isi folder ini sebagai source of truth arsitektur
- pakai hanya jika perlu melihat konteks transisi atau keputusan lama
- dokumen aktif tetap berada di `docs/`
